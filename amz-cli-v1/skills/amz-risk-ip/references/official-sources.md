# IP 检查官方来源

| 权利 | 官方入口 | 用途 |
|---|---|---|
| 美国专利 | https://ppubs.uspto.gov/basic/ | 按专利号或关键词检索授权专利和公开申请 |
| 美国专利工具 | https://www.uspto.gov/patents/basics/online-patent-tools | Patent Public Search、Patent Center 等官方入口 |
| 专利维护费 | https://www.uspto.gov/patents/maintain | 维护费、失效与期限计算说明 |
| 美国商标 | https://www.uspto.gov/trademarks/search | Trademark Search 与检索指南 |
| 美国版权记录 | https://www.copyright.gov/public-records/ | Copyright Public Records System 入口 |
| Amazon 卖家政策 | https://sell.amazon.com/blog/selling-policies | Amazon IP 与商品政策入口 |

## 证据规则

- 第三方搜索引擎可用于发现候选，但权利编号、权利人和状态应回到官方记录核对。
- `patent pending` 只说明存在声明；找到公开申请后才记录申请号和状态。
- 商标搜索要覆盖近似拼写、读音、图形元素和相关商品服务，不能只搜完全相同的文字。
- 版权记录搜索可能不完整；没有登记结果不代表作品不受版权保护。
- 保存查询词、过滤条件、目标国家和检查日期，便于正式深查复现。
